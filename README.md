# polybot — исследование рынков Polymarket

![tests](https://github.com/zenkiki-jpg/polybot/actions/workflows/tests.yml/badge.svg)

Набор логгеров и анализаторов для честной проверки торговых стратегий на рынках
[Polymarket](https://polymarket.com): 5-минутные крипто-рынки Up/Down, крипто-лесенки
«Bitcoin above ___» и погодные рынки «Highest temperature in …».

Проект начинался как бот «следуй за движением BTC», который в бумажной торговле
показывал тысячи долларов прибыли. Оказалось, что прибыль была артефактом ошибок
в данных. Дальше проект превратился в исследовательскую систему, которая собирает
реальные стаканы, сделки и официальные исходы, а потом проверяет гипотезы
с учётом комиссий, спреда, очереди заявок и проверкой на новых данных.

> **English summary.** Data loggers and analysis tools for Polymarket short-term crypto,
> crypto strike-ladder and weather markets. Everything is measured against real order books,
> real trades and official resolutions, with fees, spread, queue position and out-of-sample
> checks. Bottom line after ~2 months of data: no strategy tested here beat the market for a
> home-latency bot. See [docs/RESULTS.md](docs/RESULTS.md).

## Главные выводы

Подробно, с цифрами — в [docs/RESULTS.md](docs/RESULTS.md).

| Что проверяли | Результат |
|---|---|
| BTC 5m, тейкер «по дельте» | −1.4% на 3 716 бумажных сделках; рынок откалиброван |
| BTC 5m, логистическая регрессия (walk-forward) | цена рынка точнее модели с любыми признаками |
| 25 рынков Up/Down (5 монет × 5 интервалов) | неликвидные рынки не отстают от BTC дольше секунды |
| Мейкеры против тейкеров (реальные сделки, ~$35 млн) | мейкеры **+8.2% ± 0.3**, тейкеры **−7.0% ± 0.3** |
| Мейкер-стратегия с очередью (симуляция) | плюс только при снятии заявки быстрее ~2 с; на новых данных кандидат не подтвердился |
| Крипто-лесенки | арбитража нет (~$0.09 за 2 недели); модель по опционам Deribit ≈ рынок |
| Погода: ансамблевый прогноз | хуже рынка |
| Погода: перекос «фаворит / лонгшот» | был на одной неделе, на новых данных исчез; «переоценка» лонгшотов — это спред |
| Погода: «мёртвые корзины» по METAR | реальный плюс (94 из 94), но около +0.5% и копейки по объёму |

**Итог:** ликвидные рынки Polymarket эффективны для бота с задержкой ~1 секунда.
Деньги там у быстрых маркет-мейкеров или у тех, у кого есть информация раньше рынка.

## Что внутри

```
core/        общее ядро: рынки Gamma, стаканы CLOB, симуляция исполнения, комиссии,
             официальные исходы, потоки цен Chainlink (RTDS) и Binance, внешние API
logger/      логгеры данных
  polymarket_logger.py   BTC 5m: стаканы, все потоки цен, официальные исходы
  multi_logger.py        BTC/ETH/SOL/XRP/DOGE × 5м/15м/1ч/4ч/1д + сделки (WS и Data API)
  ladder_logger.py       лесенки "above"/"price on" + опционы Deribit
  weather_logger.py      погодные рынки + прогнозы Open-Meteo + наблюдения METAR
live/
  paper_trader.py        бумажная торговля по сетке параметров с реальными асками
analysis/    отчёты и симуляторы
  edge_report.py         EV по реальным аскам, калибровка, правило "по дельте"
  paper_report.py        итоги пейпер-трейдера
  multi_report.py        калибровка 25 рынков, сделки, опережение, мейкеры/тейкеры
  maker_sim.py           симулятор мейкера с очередью и сроком жизни заявки
  ladder_report.py       согласованность лесенки, калибровка, модель Deribit
  weather_report.py      сумма корзин, "мёртвые корзины", ансамблевая модель
  weather_strategies.py  правила фаворит/лонгшот с пессимистичной оценкой и разбивкой по периодам
  backfill_*.py          докачка официальных исходов
tests/       офлайн-тесты (сеть не нужна)
legacy/      первая версия проекта — для истории, не поддерживается
docs/        результаты исследования и шпаргалка команд
```

## Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/zenkiki-jpg/polybot.git
cd polybot
python -m pip install -r requirements.txt
python tests/test_core.py
python tests/test_multi.py
python tests/test_ladder_weather.py
```

На Windows вместо `python` можно писать `py`.

## Быстрый старт

Логгеры пишут данные в папку `data/` (она не попадает в git). Их можно запускать
одновременно, каждый в своём окне терминала.

```bash
python logger/multi_logger.py          # 25 рынков Up/Down + сделки   -> data/multi
python logger/ladder_logger.py         # крипто-лесенки + Deribit     -> data/ladder
python logger/weather_logger.py        # погода + прогнозы + METAR    -> data/weather
```

Через несколько дней можно запускать отчёты:

```bash
python analysis/multi_report.py
python analysis/maker_sim.py --since 2026-10-12
python analysis/ladder_report.py
python analysis/weather_report.py
python analysis/weather_strategies.py --since 2026-10-21
```

Полная шпаргалка — [docs/COMMANDS.md](docs/COMMANDS.md).

## Принципы, на которых построен анализ

1. **Только реальные данные:** цены из стакана, исход — из официального резолва,
   а не из собственной оценки.
2. **Все издержки:** комиссия тейкера `shares · 0.07 · p · (1 − p)`, спред,
   проскальзывание, очередь заявок для мейкера.
3. **Ошибки считаются по независимым событиям** (окнам), а не по точкам.
4. **Проверка на новых данных:** правило, выбранное на одних днях, обязано
   работать на других. Из 30 вариантов один всегда «выстрелит» случайно.
5. **Пессимистичная оценка** для правил «купить по 0.97»: 30 побед из 30 ничего не доказывают.

## Ограничения и дисклеймер

- Это исследовательский проект. **Реальной торговли в нём нет**: модуль реальной
  торговли первой версии лежит в `legacy/` и отключён.
- Ничто здесь не является финансовой рекомендацией.
- Перед любой торговлей на Polymarket проверь, разрешена ли она в твоей юрисдикции,
  и условия использования площадки.
- Форматы API Polymarket время от времени меняются. Код проверен на данных
  сентября–октября 2026 года.
