# legacy — первая версия (v1), не поддерживается

Код сохранён для истории проекта. Он построен на ошибочных предпосылках, которые
описаны в [docs/RESULTS.md](../docs/RESULTS.md) (перепутанные bid/ask, неверная цена
открытия окна, расчёт исхода по собственной цене), поэтому **его результатам верить нельзя**.

| Папка | Что это |
|---|---|
| `backtest/`, `gui/`, `data/` | бэктест на свечах Binance и GUI к нему |
| `live/real_trader.py` | реальная торговля v1 — **намеренно отключена** заглушкой в начале файла |
| `live/.env.example` | шаблон настроек для реальной торговли (без ключей) |
| `v1_analysis/` | анализаторы CSV первой версии пейпер-трейдера |
